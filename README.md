# クリーンモア 予約フォーム＋売上分析 設定手順

## 全体の流れ

```
お客様 ─ 予約フォーム(index.html) ─┐
                                   ├→ GAS → スプレッドシート ─→ 毎月1日に自動レポート（メール）
スタッフ ─ 売上入力(sales.html) ───┘    └→ お客様へ自動返信／あなたへ新規予約通知
```

| ファイル | 役割 |
|---|---|
| index.html | お客様用の予約フォーム（GitHub Pagesで公開） |
| sales.html | ミツモア・くらしのマーケット等の売上入力（スタッフ用・合言葉つき） |
| Code.gs | スプレッドシートに貼るプログラム |
| appsscript.json | GASの設定（タイムゾーン＝東京） |

---

## 手順1：スプレッドシートとGASを用意（約10分）

1. Googleドライブで新しいスプレッドシートを作成し、名前を「クリーンモア予約・売上」にする
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、**Code.gs の中身を貼り付けて保存**
4. 左の歯車「プロジェクトの設定」→「appsscript.json をエディタで表示する」にチェック → エディタに出てきた appsscript.json を **このフォルダの appsscript.json の中身で置き換えて保存**
5. 上部の関数選択で `setup` を選び「実行」
   - 「承認が必要です」→ 自分のGoogleアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
   - ※自分で作ったプログラムなので表示される警告です
6. スプレッドシートに戻り、「設定」シートで次を変更
   - `SHOP_TEL`：お店の電話番号
   - `SALES_PASSWORD`：売上入力の合言葉（スタッフに伝える）
   - `OWNER_EMAIL`：予約通知を受け取るメール（空欄なら自分）

## 手順2：ウェブアプリとして公開

1. Apps Script 右上「デプロイ」→「新しいデプロイ」
2. 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. 「デプロイ」→ 表示された **ウェブアプリのURL（https://script.google.com/macros/s/…/exec）をコピー**

> コードを修正したときは「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」。URLは変わりません。

## 手順3：フォームにURLを入れる

- `index.html` の `GAS_URL: 'ここにGASのウェブアプリURLを貼り付け'` をコピーしたURLに変更
- 同じく `SHOP_TEL` を実際の電話番号に変更
- `sales.html` の `const GAS_URL = '…'` も同じURLに変更

## 手順4：GitHub Pagesで公開

1. GitHub（cleanmoreアカウント）で新しいリポジトリ（例：`cleanmore-booking`）を作成
2. index.html と sales.html をアップロード
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後、`https://cleanmore.github.io/cleanmore-booking/` で予約フォームが開きます
   - 売上入力：`https://cleanmore.github.io/cleanmore-booking/sales.html`
   - 無料プランのPagesは**公開リポジトリ**が必要です。Code.gs と合言葉はリポジトリに置かないでください

## 手順5：テスト

1. 予約フォームから自分のメールアドレスでテスト予約 → 自動返信と通知メールが届くか確認
2. 「予約データ」にデータが入ったら、ステータスを「完了」に → 「売上データ」に反映されるか確認
3. スプレッドシートのメニュー「クリーンモア」→「先月のレポートを今すぐ作成」でレポートを確認
4. テストの行は削除してOK

## 毎日の使い方

| やること | 操作 |
|---|---|
| 新しい予約 | 通知メールが届く →「予約データ」のステータスを「日程調整中」→「確定」 |
| 作業が終わった | 確定作業日・確定金額・担当を入れて、ステータスを「完了」→ 売上に自動反映 |
| ミツモア等の仕事 | 作業後に sales.html から入力（手数料も入れると手取りが分かる） |
| リピート営業 | 「顧客台帳」の「フォロー状況」が「時期到来」のお客様に案内 |
| 月次レポート | 毎月1日 8時に自動作成＆メール。シート「レポート_YYYY-MM」に詳細 |

## 取れるデータと活かし方

- **流入経路・UTM**：どの集客が効いているか（チラシのQRに `?utm=flyer` を付けると区別できます）
- **気になる症状・メーカー・使用年数**：当日の提案トーク、10年以上なら買い替え相談の準備
- **他の掃除相談**：浴室・洗濯機などの追加受注候補リスト
- **受注経路別の手数料率・手取り**：プラットフォームと自社予約のどちらに力を入れるか判断
- **次回おすすめ時期**：1年後のリピート案内（メール配信「はい」の人へ）
